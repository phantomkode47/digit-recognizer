# Handwritten Digit Recognizer

A beginner Machine Learning project that trains a model to recognize handwritten digits (0–9).

## What it does
- Loads a dataset of 1,797 small handwritten digit images
- Trains a Logistic Regression model to recognize which digit (0-9) is shown in an image
- Tests the model on unseen images and reports how accurate it is
- Achieved **97.5% accuracy** on test data

## Tools used
- Python
- scikit-learn (machine learning library)
- matplotlib (for visualizing a sample digit)

## How to run it
```bash
pip install scikit-learn matplotlib numpy
python digit_recognizer.py
```

## What I learned
This project taught me the core Machine Learning workflow:
1. Load and understand a dataset
2. Split data into training and testing sets
3. Train a model on the training data
4. Evaluate how well it performs on data it has never seen
5. Interpret accuracy and performance metrics
